# Installing and setup

---

1. Clone the repo
```bash
git clone https://github.com/CoolGuy158-Git/NASM
```
2. Run [HDD Generator](extras/hdd_gen.py)
3. Create your file (Or use test file), it is recommended to use a .nasm extension but not required
4. Run your program
```bash
python interpreter.py {your_file.nasm} 
```

Requirements:

- psutil : for cpu clock speed info
- keyboard : to get inputs
